身体と物理モデル

詳細: @docs/agents/sim/creature.md (身体・遺伝子) / @docs/agents/sim/physics.md (積分・接触・計算構成)

身体は 6 質点・9 辺の三角補強ラダー (上下 2 列 × 3 点) です。列間隔 0.5 m、行間隔 0.4 m、全質点 1 kg、バネ剛性 100 N/m。初期形状の辺長がそのままバネの自然長になるため、最初は張りゼロで始まります。

各辺は自然長を周期的に変える筋肉です。時間積分は半陰的オイラー法 (刻み 5 ms、1 試行 5 秒)。床との接触はめり込みに比例する反力、摩擦は tanh で滑らかにしたクーロン摩擦です。RK4 も比較用に実装してあり、回帰テスト (tests/regression/) で刻みや手法を変えても結論が変わらないことを確認します。

シミュレータは JAX で書き、集団は vmap、時間は lax.scan、世代も 1 つの JIT にまとめます。世代ループの途中で CPU に結果を取り出さないため、GPU を待たせません。2D で書きつつ、質点座標や接触・摩擦の分離は 3D へそのまま拡張できる形にしています。

GA のアルゴリズム

詳細: @docs/agents/optimizer/ga.md (演算子・パラメータ・島モデル拡張・再現性の限界)

遺伝子は筋肉ごとの「振幅 (0〜0.20)」と「位相 (0〜2π)」だけです。周波数は全筋肉共通の 1 Hz で固定し、身体の形状・接続は first goal では変えません。

要素設定
集団サイズ20 (エリート 2 を継承)
選択トーナメント (k = 3)
交叉一様交叉 (遺伝子単位のスイッチ確率 0.8)
突然変異遺伝子ごとに 10%、ガウス摂動 (σ = 範囲の 5%)
評価5 秒後の重心の右向き変位のみ

無効試行 (数値発散・めり込み 10 cm 超) は距離に罰則を混ぜず、常に最下位として別扱いにします。構成は trajectory-solver-generic の BRKGA 実装 (評価と集団更新の分離) を参考にしましたが、手法自体は合意どおり標準 GA です。集団更新を純関数に分けてあるため、island model などの拡張はこの関数を島ごとに並べる形で足せます。

エネルギーの扱い

詳細: @docs/agents/fitness.md (評価式・無効判定・駆動仕事の定義)

筋肉がバネに注入した正の仕事 (駆動仕事) を毎試行で記録します。振幅の上限は常に 0.20 としますが、駆動仕事の総量による予算はオプション (--energy-budget) で、既定は無制限です。first goal では距離と仕事を並べて報告し、予算をどの水準に置くかを後で決めます。

実行コマンド

詳細: @docs/agents/operations.md (コマンド・テスト・report と review の書式)

uv sync                                        # 依存の導入 (JAX + CUDA 13)
uv run pytest -q                               # 静的テスト
uv run pytest -q -m regression                 # 積分法の回帰比較
uv run pytest -q -m slow                        # 再現性 (短い GA run)
uv run python -m bodyopt evolve --generations 10 --seed 0 \
    --record population --out resources/runs/first_try
uv run python -m bodyopt replay --run resources/runs/first_try \
    --generation 9 --rank 0

evolve は描画なしで GA を回して resources/runs/ に保存します。replay は保存した個体を同じ物理コードで再計算し、軌跡 JSON を出力します (three.js ビューアで再生)。first goal では長い GA は回さず、数分で終わる動作確認までを検証範囲とします。

記録のレベル

詳細: @docs/agents/recording.md (記録項目・再現メタデータ・viewer・動画の埋め込み)

レベル保存内容
summary世代統計と各世代の最良遺伝子、再現メタデータ (commit hash・seed・全パラメータ・実行環境)
population上記 + 全世代・全個体の遺伝子とスコア。軌跡は遺伝子と commit から再現可能
full上記 + 最良個体の完全ロールアウト (位置・速度・張力・接触・駆動仕事率の全フレーム)

分析用の記録は大切に残します。実行ごとにディレクトリを分け、上書き・自動削除はしません。

LangGraph の構造

未導入 first goal では LangGraph・LLM を使いません。固定 GA が基準となり、導入後は「数世代ごとの集計 → 停滞判定 → 診断 → 戦略適用」の分岐を LangGraph に載せ、その構造をこの節に追記します。
