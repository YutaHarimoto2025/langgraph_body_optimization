# 物理シミュレータ (src/bodyopt/physics.py)

## 重力

質点には一定の重力加速度を加える (既定 $g = 9.81\ \mathrm{m/s^2}$、`SimParams.gravity`)。

$$\mathbf{a}_i = \frac{\mathbf{F}_i^{S} + \mathbf{F}_i^{N} + \mathbf{F}_i^{f}}{m_i} + \mathbf{g}, \qquad \mathbf{g} = (0, -g)$$

- 重力項は半陰的オイラーと RK4 の両経路 (`observe` と `_forces_only`) に入れる。片方だけに入れると積分法の比較が成立しない。
- 2026-11-23 の初回実装では `gravity` パラメータを定義・記録しながら加速度に加えておらず、記録済みの runs/first_try・002 と docs/report/2026-11-23 の軌跡は重力なしで計算されている。run 003 から有効。
- 辺剛性 500 N/m (run 006 以降) では無駆動でも形が保たれる。上段は 0.45 → 0.37 m で静止し、横流れはほぼ 0 (圧縮 5%)。
- 剛性の変遷: 100 N/m (初回) は静的平衡そのものが床まで潰れた。2000 N/m は潰れないが硬すぎ、100 世代で 0.27 m しか進まなかった (run 004)。500 N/m に下げて 100 世代で 1.5 m 前後 (run 005)、500 世代で 1.96 m (run 006)。

## 筋肉モデル

辺 $e$ の張力は、受動バネと能動要素の和で表す (引く向きが正):

$$T_e = k_e\,(L_e - \bar L_e) + F_e^{A}(t)$$

能動要素は params/default.json の `sim.muscle_model` で切り替える (実装: src/bodyopt/models.py)。

| モデル | 能動要素 | 遺伝子 (振幅) | 備考 |
|---|---|---|---|
| `active_force` (既定) | $F_e^{A} = A_e\,(1+\sin(\omega_e t+\phi_e))/2$ | 最大張力 $A_e \in [0, 100]$ N | 自然長は固定。筋肉は縮む向きにだけ働く。剛性と筋力を独立に決められる |
| `rest_length` | なし ($F^A = 0$) | 自然長の振幅 $a_e \in [0, 0.20]$ | 自然長を $\bar L_e (1+a_e\sin(\omega_e t+\phi_e))$ で動かす初回実装。筋力が剛性 $k$ に比例する |

ここで $\omega_e = 2\pi f_e$、$f_e \in [0.1, 10]$ Hz は辺ごとの遺伝子。

- 遺伝子は $[A_e]$ + $[f_e]$ + $[\phi_e]$ の 3 ブロック ($3E_m$ 次元)。周波数を辺ごとに持つため、全辺が同じ周期で揃う保証はない。

- 駆動仕事率 (注入する正の仕事) はモデルごとに定義する:
  - `active_force`: $P_e = \max(0,\ -F_e^{A}\,\dot L_e)$ (辺が縮むとき正)
  - `rest_length`: $P_e = \max(0,\ -T_e\, L_e\, a_e\, \omega_e \cos(\omega_e t+\phi_e))$
- 遺伝子の上限はモデルが持つ `gene_hi` (src/bodyopt/ga.py の gene_bounds) を使う。モデルを切り替えると遺伝子の単位が変わる。
- 既存 run の meta.json には `sim.muscle_model` が残るので、replay は保存時のモデルで再計算される。

## 積分

第一候補は半陰的オイラー法 (既定 dt = 5 ms、episode 5 秒 = 1000 ステップ)。RK4 を比較候補として同ファイルに実装する。tests/regression/test_integration_scheme.py で次を検証する。

- 無駆動個体は dt 5 ms ↔ 2.5 ms ↔ RK4 で距離差 1 cm 未満。
- ランダム位相の駆動個体 (20〜40 N) は 0.01〜0.06 m で、差は 5 cm 未満。位相が揃った個体は踏切の位相が刻みに敏感になり得るため、GA 最良個体の刻み依存性は tests/regression/test_best_individual_scheme.py で測る。
- 許容差を満たさない場合は、刻みを細かくする案と RK4 を同じ候補で比較して決める。

フレーム k は時刻 t = k*dt 開始時点の状態で一貫して記録する (位置・張力・接触・駆動仕事率・自然長)。

## 辺の粘性減衰

各辺の軸方向に粘性減衰を追加できる (`SimParams.edge_damping_ratio` = ζ、既定 0.10)。辺長の変化率は両端の相対速度を辺軸へ射影して求める。

$$T_e = k_e(L_e - \bar L_e) + F_e^{A}(t) + c_e \dot L_e, \qquad c_e = 2\zeta\sqrt{k_e m_{\mathrm{eff}}}, \quad m_{\mathrm{eff}} = \frac{m_i m_j}{m_i + m_j}$$

- 減衰は辺の伸縮だけに働き、並進・剛体回転は減衰しない (単体テストで確認)。
- 減衰力の仕事率は $-c_e \dot L_e^2 \le 0$。身体全体の速度に比例する減衰は入れない。
- ζ=0 で減衰なしの力学と一致する。ζ は遺伝子に含めない (params で固定)。
- 実測 (5 秒 episode、同一遺伝子 20 回の距離幅): ζ=0 で 0.17 m、ζ=0.02 で 0.012 m、ζ=0.1・dt=2.5 ms で 0.0007 m。
- 移動距離は ζ=0 の GA 最良 1.55 m に対し、ζ=0.1 では 0.57〜0.62 m (dt 依存)。減衰は歩行の一部を奪うが、軌道は安定する。
- dt 依存性: 同じ遺伝子で dt 5 ms → 0.623 m、2.5 ms → 0.571 m、1.25 ms → 0.565 m。2.5 ms で 1% 程度に収束する。既定 dt は 2.5 ms。

## 床接触と摩擦

- めり込みに対するペナルティ反力 (法線は +y、2D 平面床の特殊ケース):

$$F_i^{N} = \max\left(0,\ k_c \max(0, -y_i) - c_c \min(0, \dot y_i)\right) \cdot \mathbb{1}[y_i < 0]$$

- 減衰項は接触中 ($y_i < 0$) だけ効かせる。接触していない落下中の質点に減衰を掛けると、空気抵抗のような上向きの力が出て自由落下が遅れる (終端速度 $mg/c_c$)。run 003 の準備中に修正した。
- 接触減衰は臨界減衰 $c_c = 2\sqrt{k_c m} \approx 89.4$ N·s/m を既定とする。初値 50 は不足減衰で接触面のトランポリン化を助長した (報告 2026-11-23)。
- 滑らかなクーロン摩擦 (sgn を tanh で近似、静止摩擦は再現しない):

$$F_i^{f} = -\mu F_i^{N} \tanh(\dot x_i / v_\epsilon), \quad v_\epsilon = 0.05\ \mathrm{m/s}$$

## 3D 拡張を見据えた一般性

- 質点座標は [N, dim] で書き、バネ力に 2D 固有の処理を入れない。
- 接触は「床の判定 + 法線反力」と「接線摩擦」を分けて実装する。3D 化では床を符号付き距離関数 (SDF) + 法線に差し替え、摩擦を接平面へ射影する。
- 自己衝突・凹凸地面・坂は first goal の対象外。

## 決定性と再現性の限界

- 質点への力の和は `.at[].add` (GPU の atomic 加算) で取る。加算順は保証されないため、同一遺伝子でも 1 ulp の差が出る。
- 減衰なし (run 006) ではこの差がカオスで増幅され、同一遺伝子のバッチ内で距離が 0.17 m ばらつき、遺伝子 $10^{-6}$ の摂動で中央値 0.27 m 変わった。記録 1.96 m に対し単体評価 1.37 m、replay 1.19 m。
- 減衰比 ζ=0.10 を入れると増幅が抑えられる。同じ遺伝子を 20 回並べた距離の幅は、dt=5 ms で 0.019 m、dt=2.5 ms で 0.0007 m (run 008)、$10^{-6}$ 摂動で 0.0002 m。
- 一方、GA 全体の再実行は一致しない (run 008 で 0.16 m 差)。スコア差 1e-4 程度でもトーナメント選択・argmax が反転し、進化の経路が変わるため。物理のカオスではなく、選択の離散性による分岐である。
- したがって個体の軌道は再現できるが、GA の世代ごとのスコア列は再現しない。run 間の比較は平均・分散で行う。
- 周波数を 0.1〜10 Hz に広げると高周波解でこの分岐が大きくなった (同じ seed の 3 世代 run で、上限 3 Hz なら 0.01 m・遺伝子差 0、10 Hz なら 1.9 m・遺伝子差 66)。周波数上限を 1 Hz にした現在は、同一 seed の run は 1e-4 以内で一致する (tests/test_reproducibility.py)。
- 新しい実験設定で run を回したら、最良個体のばらつきを `bodyopt chaos` で測る。判定基準と対処は [@docs/agents/operations.md](../operations.md) の運用ルールに従う。

## 計算構成 (同期の制約)

- CPU 版シミュレータは作らない。単体物理を jax で書き、集団軸は vmap、時間軸は lax.scan、世代軸も run_ga 内で 1 つの jit + scan に載せる。
- 世代ループ内の CPU 同期 (int()・float()・np.asarray・print) を禁止する。同期は run_ga の戻り値を tree.map(np.asarray) する最後の 1 回だけ。
- full 記録で GPU メモリが不足する場合のみ、複数世代ずつまとめて転送・保存する (初回規模では発生しない)。

## 計算資源の上限 (VRAM)

評価 (evaluate_gene) は scan 内で距離・最大めり込み・駆動仕事・接触率を累積し、フレーム列を保持しない。このため評価時のピークメモリは pop に比例し、dt・episode に依存しない。

| 条件 | ピーク VRAM | 1 世代の時間 |
|---|---|---|
| pop 10,000、dt 0.25 ms | 137 MB | 約 1.4 秒 |
| pop 100,000、dt 0.25 ms | 162 MB | 約 7 秒 |
| pop 200,000、dt 0.25 ms | 約 200 MB | 約 14 秒 |
| pop 500,000、dt 0.25 ms | 273 MB | 約 34 秒 |

- 16 GB なら pop 5×10^5 でも載る (実測)。ボトルネックは VRAM ではなく計算時間になる。
- dt 2.5 ms なら時間は約 1/10。10^5 は 1 世代 0.7 秒程度。
- 評価は EVAL_CHUNK = 50,000 個体ずつ分割して回す。5×10^5 を 1 カーネルで処理すると、分割時に比べてスループットが 1/3 に落ちる (実測)。
- 分割サイズのスイープ (5×10^5 個体、2,000 ステップ、dt 0.25 ms): 500 → 20k 個体/s、2,000 → 70k、10,000 → 174k、50,000 → 259k (最大)、100,000 → 189k、500,000 (一括) → 84k。小さすぎるとカーネル起動が、大きすぎると 1 カーネル内の効率低下が支配する。50,000 前後が最良。
- この最良点は GPU・1 個体あたりの状態量に依存する。質点・辺を増やす、または L2 の大きい GPU に変えたら再スイープする。
- 質点ごとの力の和は incidence 行列 (固定順) で取る。`.at[].add` の atomic 加算より 1.5 倍速く、加算順も決定的 (5×10^5・2,000 ステップで 2.25 秒 対 3.43 秒)。
- 駆動仕事 (energy) の統計は、それを要求すると drive の計算が生きたままになり評価が 30〜45% 遅くなる (距離のみ 1.41 秒 → 全統計 2.25 秒)。接触数・めり込み・有限判定の追加は小さい。
- 世代ごとの集団を保持するため、履歴メモリは O(世代数 × pop)。5×10^5 個体では 1 世代あたり約 85 MB 増える。500 世代では 40 GB を超えるので、大 pop × 多世代では集団履歴を保存しないモードが必要。
- 全フレームを残す rollout は replay・記録用で、こちらは 1 個体あたり 0.38 MB (dt 2.5 ms)、3.9 MB (0.25 ms)。評価に使うと dt に比例してメモリが増える。
- 集計版の評価は全フレーム版より 1 世代あたり約 20% 遅い (pop 100、2,001 ステップで 24.9 ms 対 20.8 ms)。メモリとのトレードオフ。
- 実行時間は dt に反比例し、pop に比例する。500 世代は pop 100 で約 17〜25 秒 (GPU 依存)。
