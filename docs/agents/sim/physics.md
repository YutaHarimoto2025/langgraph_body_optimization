# 物理シミュレータ (src/bodyopt/physics.py)

## 積分

第一候補は半陰的オイラー法 (既定 dt = 5 ms、episode 5 秒 = 1000 ステップ)。RK4 を比較候補として同ファイルに実装する。tests/regression/test_integration_scheme.py で次を検証する。

- 無駆動個体は dt 5 ms ↔ 2.5 ms ↔ RK4 で完全一致 (0.001 m 未満)。
- 駆動個体は位相次第で跳躍モードになり、着地位相が刻みに敏感になる (実測 0.1〜0.2 m 差)。このため駆動個体は破綻防止 (0.5 m 未満) のみ保証し、GA 最良個体の刻み依存性は tests/regression/test_best_individual_scheme.py で測る。
- 許容差を満たさない場合は、刻みを細かくする案と RK4 を同じ候補で比較して決める。

フレーム k は時刻 t = k*dt 開始時点の状態で一貫して記録する (位置・張力・接触・駆動仕事率・自然長)。

## 床接触と摩擦

- めり込みに対するペナルティ反力 (法線は +y、2D 平面床の特殊ケース):

$$F_i^{N} = \max(0,\ k_c \max(0, -y_i) - c_c \min(0, \dot y_i))$$

- 接触減衰は臨界減衰 $c_c = 2\sqrt{k_c m} \approx 89.4$ N·s/m を既定とする。初値 50 は不足減衰で接触面のトランポリン化を助長した (報告 2026-11-23)。
- 滑らかなクーロン摩擦 (sgn を tanh で近似、静止摩擦は再現しない):

$$F_i^{f} = -\mu F_i^{N} \tanh(\dot x_i / v_\epsilon), \quad v_\epsilon = 0.05\ \mathrm{m/s}$$

## 3D 拡張を見据えた一般性

- 質点座標は [N, dim] で書き、バネ力に 2D 固有の処理を入れない。
- 接触は「床の判定 + 法線反力」と「接線摩擦」を分けて実装する。3D 化では床を符号付き距離関数 (SDF) + 法線に差し替え、摩擦を接平面へ射影する。
- 自己衝突・凹凸地面・坂は first goal の対象外。

## 計算構成 (同期の制約)

- CPU 版シミュレータは作らない。単体物理を jax で書き、集団軸は vmap、時間軸は lax.scan、世代軸も run_ga 内で 1 つの jit + scan に載せる。
- 世代ループ内の CPU 同期 (int()・float()・np.asarray・print) を禁止する。同期は run_ga の戻り値を tree.map(np.asarray) する最後の 1 回だけ。
- full 記録で GPU メモリが不足する場合のみ、複数世代ずつまとめて転送・保存する (初回規模では発生しない)。
