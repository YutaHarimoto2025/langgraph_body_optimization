# 概要・範囲・ロードマップ

## first goal

LangGraph・LLM・feedback 制御 (脳) を導入せず、**固定形状の 2D 質点・バネ身体に対して周期制御のみを遺伝子とする純粋 GA** が動くこと。完了条件は次のとおり。

1. 静的テスト・積分法回帰テスト・短い GA run での再現性テストが通る。
2. 数分で終わる GA run (既定 10 世代 × 20 個体) で初期世代から best score が改善する。
3. 保存した個体を同じ物理コードで再ロールアウトして再生できる。

最適化対象の拡張 (形状・トポロジー・ノード数) は first goal 達成後に段階的に行う。

## ロードマップ

- 形状探索 (初期座標を遺伝子に追加、接続固定) → トポロジー → ノード数可変 (docs/open/0912_...md の Level 2-3)。
- LangGraph 導入: 固定 GA を基準に、停滞診断・戦略変更の分岐を追う。
- feedback 制御: 周期制御を基準に、状態入力の制御器 (Rojas 2025 の attention 共有制御を参考) を比較。
- Three.js ビューアの強化 (分析パネル・複数個体比較・shadcn/ui)。
- 跳躍解への対処 (報告 2026-11-23 の判断事項)。評価式を変えるため、比較方式間で固定する条件を同時に決める。
