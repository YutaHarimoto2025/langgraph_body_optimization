人工身体の最適化：GPU 前提の技術選定

元のアイデアメモの §9「Level 1」と §11「最初の実装イメージ」を対象にします。2D の質点・バネ身体の接続を固定し、遺伝的アルゴリズム（GA）で形状と筋肉の制御を探索します。LangGraph で停滞時の判断、戦略変更、失敗時の復帰を追えるか確かめます。接続の変更、LLM による身体の直接設計や探索コードの生成は次段階に回します。

おすすめ：Linux の NVIDIA GPU 1枚で、Python 3.12・uv・JAX を使います。GA と物理評価をまとめて GPU で実行し、LangGraph は数世代ごとに集計値だけを受け取ります。進化中は描画せず、見たい個体だけ別コマンドで再生します。まず固定 GA と模擬応答で動作を確認し、次に実際の LLM を使います。

3. 探索と評価

3-1. GA のライブラリ

evosax 公式リポジトリで、集団を初期化してから候補生成・評価・更新を繰り返すインターフェースを確認できます。

参考実装：trajectory-solver-generic の BRKGAでは、集団行列 [候補数, 遺伝子数] をまとめて評価し、乱数キーの分割、エリート継承、交叉を JAX の配列演算で行っています。本案はこのデータの持ち方を参考にしますが、最小化用の BRKGA や毎世代のスコア取り出しは流用しません。重心の右向き変位を最大化し、世代ループもまとめてコンパイルします。

3-2. スコアと無効候補
3-3. 試行予算とシード
3-4. 比較する方式

GA の初期設定案：集団20、3個体のトーナメント選択、一様交叉率0.8、遺伝子ごとの突然変異率0.10。変異は各変数の探索幅の5%を標準偏差とするガウスノイズとし、位相は周期で折り返し、他の値は範囲内に収めます。前世代の上位2個体は再評価せず、新規20候補の下位2個体と合わせた4個体から上位2個体を選び、次世代の集団を20に保ちます。
