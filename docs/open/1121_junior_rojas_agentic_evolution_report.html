Junior Rojas の人工身体研究と GA を監督するエージェント

先行研究調査｜2026年11月21日

Rojas は2016年に柔らかい身体の筋肉制御を遺伝的アルゴリズム（GA）で探索し、2025年には同じ制御器で二足と四足を動かしました。確認した本人の公開資料では、大規模言語モデル（LLM）が進化の停滞を見て GA の戦略を変え、その効果を次の世代で確かめる実験は見当たりませんでした。他の研究には近い先行例があるため、このプロジェクトでは「どの停滞にどの介入が効くか」を比較するのが有望です。

Rojas は固定形状の歩行進化から、二足・四足での制御器共有まで実演した

本人の公開資料で確認した内容
公開物実際に行ったこと実験の範囲
2016年：GA 歩行デモ [1]変形する三角形の辺を筋肉とし、各辺を周期的に収縮させる周波数を遺伝子にしました。短時間の移動で個体を選び、交叉・突然変異で制御を改善しました。身体そのものは変えていません。時刻だけを入力する制御で、状態に応じて筋肉を動かすフィードバックはありません。
2019年：2D 柔軟体の強化学習 [2]三角形メッシュの頂点位置・速度を身体の座標系に直して入力し、筋肉の自然長を変える制御器を学習しました。水平移動と跳躍を別々に訓練し、外から力を加えた状態からの回復も実演しています。GA による形態探索ではありません。水平移動の報酬は身体の局所座標系の水平変位で、本プロジェクトの質量重み付き重心の変位とは定義が異なります。
2021年：微分可能な陰的柔軟体物理 [3]陰的な時間更新をエネルギー最小化として記述し、自動微分から制御学習に必要な勾配を計算しました。論文の移動課題ではモデルフリー強化学習より少ないサンプルで学習できたと報告しています。物理ステップと制御学習の研究です。本プロジェクトの GPU 上の GA より速いと示したわけではありません。
2024年：Algovivo [4]弾性三角形、筋肉、重力、地面との衝突、摩擦、慣性をエネルギー項に分けた柔軟体シミュレータです。C++・Enzyme の実装を WebAssembly 向けにビルドし、JavaScript から動かせるデモを公開しています。ブラウザで身体の挙動を観察する参考になります。公開例は JAX で集団を一括評価する GPU GA ではありません。
2025年：形態に適応する Attention 制御 [5]静止形状での頂点位置をキーとし、現在の位置・速度を参照します。各筋肉が同じ制御器を使って必要な頂点情報を取り出し、一組の学習済み重みで二足（28頂点・19筋）と四足（62頂点・38筋）を動かしました。二形態とも訓練対象です。形態ごとに訓練済みの制御器が作った軌跡を教師にした模倣学習で、未学習の形態への汎化、形態の進化、移動のゼロからの学習を示した実験ではありません。

2025年の Attention は、身体の状態を読み、筋肉を動かす制御器の一部です。LLM に似た注意機構を使っていても、世代をまたいで結果を読み、進化戦略を変えるエージェントとは役割が違います。

初回は周期制御と再生の分離を参考にする

身体を固定した対照を残す

2016年のデモでは、周期制御だけでも移動が生じました [1]。こちらでは、接続と初期形状を固定して振幅・位相だけを探索する対照を残すと、初期形状も探索した場合の上積みを切り分けられます。Rojas は周波数を探索しており、本プロジェクトの共通周波数・可変振幅・可変位相とは別の設定です。まずは現在の仕様を変えずに比較します。

材質と駆動を分けて診断し、軌跡は必要なときにだけ作る

Algovivo のように、構造の弾性、筋肉の駆動、地面との接触を個別に点検すると、進まない原因を切り分けやすくなります。初回から三角形の有限要素モデルや陰的積分に置き換える必要はありません。2025年の公開コードは軌跡生成と描画を別工程にしています [5]。こちらも進化中は JAX で距離や接触・無効判定を集計し、気になる個体だけ同じ物理コードで再生します。

接続や質点数を変える段階で、制御器の共有を試す

2025年の方法を参考に、各筋肉へ同じ小さな制御器を適用すれば、筋肉が増減するたびに出力層を作り直さずに済みます。まずは各筋肉の長さ・伸縮速度・端点の接触を使う共有制御を比較し、遠くの頂点の情報も必要なら Attention を試します。論文では理想軌跡から外れることがあり、問題が起きた状態からの参照軌跡を追加すると改善しました [5]。こちらでも訓練に使わない形態・摩擦・初期姿勢を分け、同じ制御器の重みのまま移動できるかを評価します。

Rojas の公開資料では未確認だが、近いエージェント研究はある

本人サイトと公開リポジトリ一覧、そこからたどれる主要資料を確認しました [0]。身体の候補を LLM が提案する実験、LLM が GA の演算子を選ぶ実験、LLM が探索アルゴリズムを生成する実験は、今回確認した Rojas の資料には見当たりません。これは公開資料についての判断で、未公開の活動や分野全体の新規性を示すものではありません。

  • 今回調べた中では LAOS（Zhang・Yi、2025年）がGA を監督する案に最も近い先行例です。進捗・最良スコア・集団の多様性と演算子の実績を LLM に渡し、進化計算で使う演算子を適応的に選びます。本プロジェクトでは、滑りや跳躍、数値発散の情報も渡すと、同じ戦略候補からより適切なものを選べるかを問えます。
  • RoboMorph と Auto-Robotist は、LLM が身体を提案する案に近いです。前者は文法で表した部品構成を進化的に改良します。後者は EvoGym のボクセル身体を探索し、評価した設計を根拠付きの自然言語ルールとして蓄積し、次の設計提案に使います。「評価→内省→再提案」や「失敗を記憶する」だけでは差になりません。
  • LLaMEA は 探索アルゴリズム自体を設計する案の先行例です。アルゴリズムの生成・変異・評価を繰り返します。最初はこの段階まで広げず、同じ GA の中で戦略の選び方だけを変えます。
  • Evolution and learning in differentiable robots は、形態の進化と制御学習の比較に向いています。外側の GA が形態を変え、個体の制御器は並列の微分可能シミュレーションで訓練します。形態と制御を別の段階で最適化する先行例で、LLM による監督とは異なります。

同じ停滞状態から分岐させて、介入の選び方を比べる

最初に検証する問い：距離・有効率・多様性だけを見る場合に比べ、接触や挙動の集計も見た LLM は、同じ評価予算でよりよい GA 戦略を選べるか。

まず GPU 前提の技術選定案に沿い、接続固定の 2D 質点・バネ、重心の右向き変位、描画なしの JAX 評価を使います。LangGraph は5世代ごとに集計を受け取り、停滞時には「継続」「次の世代だけ変異を強める」「次の世代の新規候補の一部を置換」のいずれかを適用します。評価式は固定し、滑りや跳躍などの観測値は診断にだけ使います。LLM に身体・評価式・コードを同時に変更させると、何が改善に効いたか分からなくなるためです。

  1. 探索全体を比較します。固定 GA、ルール介入 GA、LLM 介入 GA を、同じ初期集団・候補予算・複数シードで実行します。介入する方式は同じ停滞判定と戦略候補を使います。LLM には、数値集計だけを渡す条件と、接触率・接地中の横滑り・滞空率・無効理由も渡す条件を設けます。
  2. 介入の効果を別に測ります。一部の停滞時点で集団と乱数状態を保存し、同じ状態から継続・変異強化・部分置換をそれぞれ試します。各分岐に同数の候補評価を割り当て、5世代後の改善量で比べます。追試結果はその場の戦略選択に使わず、探索本体と別に費用を記録します。これで「介入後に改善した」と「その介入を選んだために改善した」を区別しやすくなります。
  3. 判断とその結果を結び付けて残します。候補数に対する最良距離、有効率、実行時間、LLM 呼び出し数を方式別に記録します。各介入では入力・選択・理由・適用後の改善を対応付け、滑って進む個体や滞空で距離を稼ぐ個体は必要に応じて再生します。評価回数が減っても時間や費用が増える場合は、両方を報告します。

固定形状で比較手順を確認したあと、元の計画どおり接続を固定したまま初期形状も探索します。そこで「形状と制御のどちらを変えるべきか」が診断の対象になります。複数の身体へ学習済み制御を移す実験は、同じ重みで未学習形態を動かせるかという独立した問いとして扱います。
